# EquityTrace v1.0.0 — release notes (prepared)

Status: **release candidate documentation**. This file prepares the v1.0.0
narrative. Creating the annotated tag and publishing the GitHub Release require
separate, explicit approval after the release-candidate PR is reviewed and
merged.

Latest previously published release remains **v0.3.2** until that approval.

## What v1.0.0 delivers

Cumulative product through v0.3.2 plus the v1.0 research presentation layer:

- SEC/XBRL ingestion with issuer vs security identity
- Point-in-time financial statements and restatement-aware snapshots
- Traceable fundamental factors and cross-sectional rankings
- Market ingestion (raw + provider-adjusted bars), PIT shares, market cap
- Valuation factors and momentum / volatility / beta / drawdown analytics
- Native weight-return portfolio research backtests
- Equal-weight, inverse-volatility, and skfolio minimum-variance target weights
- DuckDB persistence for portfolio runs, rebalances, transitions, and equity
- Typed research strategies with economic fingerprints
  (`equitytrace research validate|run|show`)
- Standalone offline HTML research reports and deterministic JSON exports
  (`equitytrace research report|export`)
- Leakage auditing and standing methodology warnings
- Offline synthetic demonstration (`scripts/demo_research.py`)

## Honest limitations

- Provider-adjusted history is **not** vendor-vintage point-in-time price history
- User-supplied universes can embed **survivorship bias**
- Point-in-time financial evidence is not the same as perfect vintage market-price
  completeness
- Same-issuer multi-security universes are unavailable (no share-class guess)
- Weight-return research is **not** a broker share/fill ledger
- No live trading, broker APIs, or execution simulation
- Outputs are reproducible research artifacts, **not investment advice**
- No performance guarantees or profitable-strategy claims

## Packaging

- Package version: `1.0.0`
- Runtime dependency pin retained: `skfolio==1.2.3`
- Interface: CLI + offline HTML (no web framework)
